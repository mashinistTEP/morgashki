# add_railway_line.py — добавление дороги (подгруппы) внутри компании

## Что это такое

Компания-перевозчик (БЧ, РЖД) может делиться на конкретные дороги —
например РЖД включает МЖД, ОКТ.ЖД, КЛД.ЖД и т.д. В списке локомотивов
это отображается так:

- Сразу под заголовком компании — ряд маленьких кнопок с названиями дорог
- Пока ни одна не выбрана — показываются только локомотивы **без**
  привязки к конкретной дороге (общий состав компании)
- При нажатии на кнопку дороги — список заменяется на локомотивы **этой**
  дороги (общий состав скрывается)
- Повторное нажатие на ту же кнопку — снимает фильтр, возврат к общему составу

## Как использовать

1. Скопируй `add_railway_line.py` в корень проекта (рядом с
   `add_locomotive.py` и `build.gradle.kts`).

2. Запусти:
   ```bash
   python3 add_railway_line.py
   ```

3. Выбери компанию (БЧ/РЖД/другая, если уже добавлена через
   `add_railway_group.py`), к которой относится новая дорога.

4. Введи короткий код дороги (латиницей, например `MZD`) и полное
   название (например «Московская железная дорога»).

5. Скрипт покажет, что добавит, и попросит подтверждения.

6. После вставки — предложит закоммитить и запушить.

## После добавления дороги

Когда будешь добавлять локомотив этой дороги через `add_locomotive.py`,
скрипт сам покажет список доступных дорог выбранной компании и предложит
выбрать нужную (или оставить локомотив без привязки к дороге — пункт
«0» в списке).

## Важно

- Не даст добавить дубликат кода дороги — остановится с ошибкой и
  ничего не тронет.
- Перед сохранением проверяет баланс скобок/тегов — если что-то не
  сходится, файлы не изменяются вообще.
- Дороги привязаны к конкретной компании (`parentGroup`) — при выборе
  компании в `add_locomotive.py` показываются только дороги именно этой
  компании, а не все существующие в проекте.
