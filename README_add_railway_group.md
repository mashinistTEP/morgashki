# add_railway_group.py — добавление новой компании-перевозчика

## Как использовать

1. Скопируй `add_railway_group.py` в корень проекта `android_project_v2`
   (туда же, где `build.gradle.kts` и `add_locomotive.py`).

2. Запусти:
   ```bash
   python3 add_railway_group.py
   ```

3. Ответь на вопросы:
   - **Короткий код** — латиницей заглавными буквами, без пробелов
     (например `KLD` для Калининградской ЖД). Это машинное имя,
     используется в коде как `RailwayGroup.KLD`.
   - **Полное название** — то, что реально увидит пользователь в списке
     локомотивов как заголовок группы (например «Калининградская
     железная дорога»).

4. Скрипт покажет, что именно будет добавлено, и попросит подтверждения.

5. После подтверждения — правит два файла:
   - `Locomotive.kt` — добавляет новую константу в `enum class RailwayGroup`
   - `strings.xml` — добавляет строку с названием компании

6. Предложит сразу закоммитить и запушить.

## После этого

Когда будешь добавлять локомотив этой компании через `add_locomotive.py`,
на вопрос "Группа — БЧ или РЖД?" просто введи свой новый короткий код
(например `kld`, регистр неважен) — скрипт `add_locomotive.py` и так
принимает произвольную строку, никаких дополнительных правок для этого
не требуется.

## Важно

- Скрипт не даст добавить дубликат — если код уже существует в
  `RailwayGroup`, остановится с ошибкой и ничего не тронет.
- Как и `add_locomotive.py`, перед сохранением проверяет баланс скобок —
  если что-то не сходится, файлы не изменяются вообще.
- Порядок групп в самом списке локомотивов (какая компания показывается
  выше/ниже) определяется не этим скриптом, а порядком, в котором ты
  потом добавляешь сами локомотивы через `add_locomotive.py` — группа
  впервые появится в списке там, где будет первый локомотив с этим кодом.
