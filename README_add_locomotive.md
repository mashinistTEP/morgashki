# add_locomotive.py — автодобавление локомотивов

## Как использовать

1. Скопируй `add_locomotive.py` в корень проекта `android_project_v2`
   (туда же, где лежит `build.gradle.kts`).

2. Заранее положи все PNG-файлы нового локомотива в
   `app/src/main/res/drawable-nodpi/` с именами вида:
   ```
   код_fon.png
   код_bufer_l.png
   код_bufer_r.png
   код_red_bufer_l.png
   код_red_bufer_r.png
   код_projector.png        (или код_projector_l.png + код_projector_r.png)
   ```

3. Открой калибратор, подгони буферы нового локомотива, скопируй JSON
   (кнопка "Скопировать координаты").

4. Запусти в Termux из корня проекта:
   ```bash
   python3 add_locomotive.py
   ```

5. Отвечай на вопросы по порядку:
   - Название (например «ЭП2К-220»)
   - Короткий код (латиницей, например «ep2k»)
   - Именной ли локомотив → если да, собственное имя
   - Группа: bch или rzd
   - "На маршруте" ли (если да — остальные вопросы про фон/буферы пропускаются)
   - Готов ли фон
   - Есть ли красные буферы
   - Есть ли прожектор → если да, раздельный ли (как у БКГ1) или один
   - Вставляешь блок координат из калибратора (JSON), затем пустая строка + Enter

6. Скрипт покажет сгенерированный код — подтверждаешь вставку.

7. Скрипт сам проверит, что все нужные PNG-файлы на месте (если чего-то
   не хватает — остановится и покажет, каких файлов не хватает, ничего
   не испортив).

8. После вставки — предложит сразу закоммитить (`git add .`) и запушить
   (`git push origin main`). Соглашаешься → вводишь сообщение коммита →
   при пуше вводишь логин/токен как обычно.

## Важно

- Скрипт **никогда** не сохранит файл, если после вставки нарушится
  баланс скобок — в этом случае просто выведет ошибку и ничего не тронет.
- Новый локомотив всегда добавляется **в конец своей группы** (БЧ или
  РЖД), а не в конец всего файла — порядок группировки в списке
  сохраняется.
- Если введёшь код, который уже используется — дублирования не будет
  запрещено на уровне скрипта, так что перед стартом стоит один раз
  проверить `grep "код" LocomotiveCatalog.kt`, чтобы не задвоить.
